# Muzora

Lightweight YouTube Music-inspired web player (SimpMusic style).

## Stack (updated)
- Next.js **16.3.6** (latest patched)
- React 19.3
- Tailwind CSS 3.4
- TypeScript 5.9

## Features
- Fast search + instant audio streaming (Piped)
- Mini player + Full player with blur album art
- Bottom navigation (Home / Search / Library)
- Mood chips & Moods & Moments cards
- Sleep Timer (15 / 30 / 45 / 60 min)
- Shuffle & Repeat (off / all / one)
- Like / Favorite songs
- Recently Played history
- Queue viewer
- **Playlists** (create, add, play, delete)
- Dark glassmorphism UI

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
Just push to GitHub — Vercel auto-detects Next.js.
